# V4 UI 布局规格（依据主人 2026-11-01 手绘线框）

> 本文件是 UI 布局的最终依据，优先级高于此前所有布局描述。视觉风格仍按"最华丽的动效/光影美学"执行。

## 窗口形态
- 默认窄窗（线框约 407×100 单位比例 → 实际建议 420×680 起步，可缩放，响应式到 1400px）。

## 结构（从上到下）

### 1. 顶栏（容器5）
- 左：**鲸鱼名字**，默认可自定义（"可自定义名字啥的，默认显示你的鲸鱼名字"）。名字可在设置里改，存 localStorage + 后端 state。
- 右：**圆形头像**（"可以展示给小鲸鱼的头像一类的"）——用自绘 SVG 鲸鱼头像，带呼吸/眨眼动效，点击可切换静音/在场状态。

### 2. 导航标签（一行五个，等宽胶囊）
聊天 | 互动 | 历史画作 | 小鲸鱼的工具 | 设置
- 当前页高亮（渐变描边+微光）。
- 对应关系：
  - 聊天 = 对话页（含轮次分组、右侧轮次定位条、回到底部按钮）
  - 互动 = 原状态页 + 摸头/戳/投喂/一起玩/叫醒 等互动动作（状态头像、能量环都在这里）
  - 历史画作 = 原画廊（修复抽搐）
  - 小鲸鱼的工具 = 表情渲染、生图快捷入口、语音入口等能力工具箱（后续扩展位）
  - 设置 = 名字/令牌/外观/**部署模式**（见下）/关于

### 3. 左侧细栏（容器2左边的窄条）
- "可任意放一些状态头像什么的"：一列小状态徽章（能量/心情/饥饿/静默/在线），hover 出 tooltip，点击跳转"互动"页。
- 窄（约 40px），不抢主区空间。

### 4. 主内容区（容器2）
- 聊天页主区。滚动容器规则不变：overflow-y:auto、上滚停止跟随、右侧轮次定位小横条保留。

### 5. 底部发送栏（容器3）
- 输入框 + 发送按钮，固定在底部，不随内容滚动。

## 首次启动流程（重要，新增）
线框下方文字：
1. 第一次打开后**询问是否有服务器部署**；
2. 选择"有" → 再选类型：**终端** 还是 **服务器**；
3. 选择"没有" → **本地部署**（launcher 静默拉起本机后端）；
4. 之后可在**设置**里改部署模式（单机/终端/服务器）。

实现要求：
- 首次启动显示引导弹层（三步单选，风格与 splash 一致）；
- 选择结果持久化（localStorage + 可选同步后端）；
- "服务器"模式：让用户填 base_url + token，前端直连远程后端；
- "终端"模式：本机已有后端（launcher 拉起），前端连接本地；
- "本地部署"：默认模式，等同现在的行为；
- launcher（task-21）读取同一份部署配置：本地/终端模式才拉后端，服务器模式不拉后端只开前端。部署配置约定文件：data/deployment.json {"mode": "local|terminal|server", "server_url": "", "token": ""}，launcher 与前端都读它（launcher 优先读环境变量覆盖）。
